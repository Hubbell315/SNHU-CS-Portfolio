# CS 405: Secure Coding

This folder contains my portfolio artifacts from CS 405: Secure Coding at Southern New Hampshire University. Throughout this course, I learned how security should be incorporated into every stage of software development rather than added after an application has already been completed.

## Course Artifacts

### Project One: Security Policy

For Project One, I developed a C/C++ security policy for Green Pace. The policy establishes secure coding standards and covers areas such as input validation, memory management, exception handling, encryption, authentication, authorization, auditing, least privilege, and defense in depth. It also includes risk assessments, enforcement procedures, automated testing recommendations, and guidelines for maintaining the policy as new threats emerge.

### Project Two: Security Policy Presentation

For Project Two, I created a narrated presentation explaining the security policy developed during Project One. The presentation summarizes the identified risks, secure coding standards, security controls, testing methods, and recommendations for applying the policy throughout the software development life cycle.

### Secure Coding Activities

The coding ZIP files contain C++ activities completed throughout the course. These activities demonstrate secure coding practices involving:

* Integer overflow and underflow
* Exception handling
* Unit testing
* Encryption
* Static code analysis
* Risk identification and mitigation

### Portfolio Reflection

The Module Eight portfolio journal reflects on how this course changed the way I approach software development. It discusses adopting secure coding standards, incorporating security from the beginning, evaluating risk and remediation costs, applying zero-trust principles, and implementing enforceable security policies.
