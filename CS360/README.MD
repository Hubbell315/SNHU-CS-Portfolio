# CS 360 - Mobile Architecture and Programming

Project Overview and User Needs
The mobile application developed for this project is a calendar-based reminder app designed to help users create, manage, and track scheduled events. The primary goal was to provide a simple and reliable system for storing event information and receiving notifications for important dates. This application addresses a straightforward yet essential user need: the requirement for an organized system to manage reminders, appointments, or deadlines in a structured and accessible format. By focusing on dependability and ease of navigation, the app ensures that users can quickly input and retrieve information without the confusion often found in more cluttered task management tools.

Screens, Features, and User-Centered Design
To support these user needs, the app incorporates core screens for event creation, event listing, and notification handling. Persistent data storage was a critical feature, ensuring that reminders remain available and intact even after the app is closed or the device is restarted. The user interface was designed with clarity and simplicity as the priority, featuring straightforward navigation and clearly labeled input fields. These design decisions were successful because they reduced cognitive load and allowed users to complete their intended tasks efficiently. By prioritizing readability and a consistent layout, the UI remains intuitive for a wide range of users.

Development Approach and Techniques
The coding process followed an incremental development strategy, where each feature was built and tested individually before being integrated into the broader application. This modular approach focused on maintaining an organized code structure, utilizing clear naming conventions, and separating user interface logic from data handling wherever possible. These techniques improved maintainability and made the debugging process much more manageable. Such strategies are highly transferable to future professional projects, as incremental development and structured organization promote long-term scalability and significantly reduce technical debt.

Testing and Validation
To ensure full functionality, the application was rigorously tested using both an emulator and a physical device. This process involved verifying user input validation, data persistence, and notification triggers under various scenarios. Testing was an essential phase of development because it revealed small usability issues and logical errors that were not immediately apparent during the initial coding phase. This experience reinforced the importance of continuous testing throughout the entire development cycle, rather than postponing evaluation until the final stages of the project.

Innovation and Problem Solving
A significant challenge encountered during development involved ensuring reliable persistent storage and proper event handling across various lifecycle changes. I had to troubleshoot data inconsistencies and refine the specific methods used to store and retrieve information. Addressing this challenge required researching industry best practices and carefully restructuring portions of the code to maintain data integrity. This experience strengthened my problem-solving skills and provided a much deeper understanding of mobile application architecture and the complexities of the Android activity lifecycle.

Demonstration of Knowledge and Skills
The implementation of structured navigation and persistent data storage represents a major success in demonstrating my technical skills. These components highlight a strong understanding of Android activity lifecycle management, user-centered design principles, and functional mobile application architecture. The final product reflects both technical functionality and thoughtful design, representing meaningful growth in my professional development process. This project serves as a comprehensive example of my ability to build a functional, user-focused mobile solution from the ground up.
