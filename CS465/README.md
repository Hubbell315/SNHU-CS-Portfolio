# CS 465: Full Stack Development I

## Travlr Getaways

Travlr Getaways is a full-stack travel management application developed during CS 465. The project includes a customer-facing website, an Angular single-page application for administrative users, an Express.js REST API, and a MongoDB database.

The administrative application allows authenticated users to view, add, and edit travel packages. Security features include Passport.js credential validation, password hashing and salting, JSON Web Token authentication, protected API routes, and an Angular HTTP interceptor.
