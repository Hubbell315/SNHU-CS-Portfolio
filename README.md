# Tyler Hubbell | Computer Science Portfolio

This repository contains selected projects and coursework completed throughout my Bachelor of Science in Computer Science program at Southern New Hampshire University, with a concentration in Software Engineering.

The work demonstrates experience across full-stack development, secure coding, databases, software testing, mobile development, computer graphics, embedded systems, and artificial intelligence. Each course folder contains its own README explaining the project requirements, technical decisions, challenges, and skills demonstrated.

## Featured Coursework

### [CS 465: Full Stack Development](./CS465)

Developed Travlr Getaways, a full-stack travel application using the MEAN stack. The project includes a customer-facing website, an Angular administrative interface, RESTful API endpoints, MongoDB persistence, and JWT-based authentication.

### [CS 405: Secure Coding](./CS405)

Developed a C/C++ security policy based on secure coding principles and industry standards. The portfolio includes risk assessments, secure coding standards, C++ activities, unit testing, static analysis, encryption policies, zero-trust concepts, and recommendations for incorporating security throughout the software development life cycle.

### [CS 340: Client/Server Development](./CS340)

Applied database design and client/server development concepts using MongoDB, Python, and data visualization. The coursework demonstrates database queries, CRUD operations, application integration, and presenting stored data through an interactive interface.

### [CS 330: Computational Graphics and Visualization](./CS330)

Created an interactive 3D scene using C++ and OpenGL. The project demonstrates object modeling, textures, lighting, transformations, camera movement, and rendering within a real-time graphical environment.

### [CS 320: Software Testing, Automation, and Quality Assurance](./CS320)

Developed and tested software using unit testing, validation, and automated quality-assurance practices. The coursework focuses on translating requirements into reliable functionality and verifying behavior through structured tests.

### [CS 370: Current and Emerging Trends in Computer Science](./CS370)

Applied artificial intelligence and reinforcement-learning concepts to solve computational problems. The coursework explores neural networks, intelligent agents, algorithmic decision-making, and the ethical use of emerging technologies.
